Morse Code Transmitter and Receiver


Overview

This project implements a Morse code transmitter and receiver using AVR microcontrollers and Embedded C.

The system transmits Morse code using an LED and receives the signal through an LDR (Light Dependent Resistor). The receiver decodes the optical signal and reconstructs the transmitted message.

Features

Morse code encoding and decoding
Optical communication using LED and LDR
AVR microcontroller implementation
ADC-based signal detection
Real-time transmission and reception
Serial terminal output
